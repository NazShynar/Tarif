# Страница тарифов

Как выложить на GitHub Pages:

1. Создайте репозиторий на github.com (кнопка **New**), например `tarify`.
2. Загрузите файл `index.html` (Add file → Upload files) и нажмите **Commit changes**.
3. Откройте Settings → Pages → Source: **Deploy from a branch**, ветка **main**, папка **/ (root)** → Save.
4. Через 1–2 минуты сайт будет по адресу `https://ВАШ_ЛОГИН.github.io/tarify/`.

Номер WhatsApp: откройте `index.html`, найдите строку `var WA_PHONE=""` и впишите номер без «+», например `77001234567`.

Тарифы: кнопка «Загрузить Excel» на странице. Шаблон: `tarify-5.xlsx`.
